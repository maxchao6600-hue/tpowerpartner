# TPOWER Partner

Official affiliate and partnership program website for TPOWER Partner — a professional performance-based partnership platform for affiliates, media buyers, content creators, and traffic partners.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Fonts:** Syne (display), Inter (body), IBM Plex Mono (labels)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Pages

- `/` — Homepage
- `/why-tpower` — Partnership proposition
- `/how-it-works` — Program process
- `/commission` — Commission model
- `/resources` — Partner resources
- `/faq` — Frequently asked questions
- `/contact` — Partner support
- `/login` — Partner login
- `/register` — Partner application
- `/terms` — Terms & Conditions
- `/privacy` — Privacy Policy
- `/responsible-gaming` — Responsible gaming information

## Environment

Optional environment variable:

```
NEXT_PUBLIC_SITE_URL=https://tpowerpartner.com
```

## Deployment

The site is statically generated and can be deployed to any platform supporting Next.js (Vercel, Cloudflare Pages, etc.).

```bash
npm run build
```
